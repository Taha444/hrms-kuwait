## الحالة
```
Build:    v1.0.0
Commit:   3a74741
الحكم:    NO-GO
البنود:   102 بعد إزالة التكرار (33 blocker · 36 high · 25 medium · 7 low)
```

## النطاق
هذا الكيت مبني من ثلاثة مصادر مراجعة متداخلة:
- **FUR** — Final User Readiness Review (الأحدث)
- **RT** — Retest Findings (23 بندا، يستخدم صيغة «لسه»)
- **QA** — QA Observations (31 بندا، الأقدم)
- **BLK / SPEC** — الأخطاء المانعة + باقي تنفيذ V1.5 و V2.2
- **API** — بلاغان مباشران على endpoints

تم دمجها وإزالة التكرار منها، **وتعليم ثمانية تناقضات** حيث تقول قائمة «مكسور» وأخرى «اتصلح».

## قواعد حاكمة من طلب المراجعة نفسه
- **لا Scope جديد** ولا تحسينات شكلية جانبية — قائمة تنفيذ محددة فقط.
- **لا Build جديدة أثناء الـ Retest النهائي.**
- الـ Retest القادم **مركّز على البنود فقط، وليس Audit جديدا**.
- التسليم يحتاج: Full Commit SHA · وقت الـ Deployment · Migration Version · وحكم Fixed/Not Completed أمام كل بند.

## مبدأ العمل: الجذر قبل العرَض
102 بند ليست 102 شغلة. معظمها يشترك في ستة جذور:

| الجذر | عدد التوابع |
|---|---|
| مصدر صلاحيات غير موحّد (Menu/Route/API/Button) | ~10 |
| غياب `current_assignee` حقيقي في المهمة | ~4 |
| نموذج عام واحد لكل الطلبات | ~5 |
| مصدر بيانات منفصل لكل شاشة | ~6 |
| غياب `employee_id` في المستخدم | ~3 |
| خلط Preview بالإصدار | ~3 |

**اسأل دائما قبل أي إصلاح: كم بند تاني في السجل ليه نفس الجذر؟**

## ترتيب العمل
```
1. /hrms-conflicts       ← قد يكون ربع القائمة مُصلحا بالفعل
2. API-01                ← بدونه نصف الاختبارات مستحيلة
3. ACCESS-01, ACCESS-12  ← بدون هوية سليمة، اختبار الأدوار غير موثوق
4. WF-01 + WF-02         ← نفس الجذر، معا
5. CAT-01 + API-02       ← الكتالوج
6. ATT ثم PAY            ← الحضور مدخل الرواتب
7. باقي المانعات
8. high ثم medium ثم low
9. OPS-05                ← انضباط الـ Retest، آخر شيء
```

## قاعدة الإغلاق
السكريبت **يرفض** `--set X fixed` بلا `--note`. الدليل المقبول: commit + ملف اختبار · مخرَج فعلي · خطوات إعادة اختبار فشلت في التكرار.

## ما يبطل أي إصلاح
- إصلاح في CSS أو Frontend لمشكلة خصوصية أو أمان
- catch أو إخفاء لخطأ الخادم بدل إصلاحه
- اختبار على شركة واحدة فقط (GUF و MUF يسلكان مسلكا مختلفا — بلاغ API-01 يثبت ذلك)
- «شغّال عندي» بلا خطوات قابلة للتكرار
- تعديل بند ثبت أنه سليم (انظر `--conflicts`)
