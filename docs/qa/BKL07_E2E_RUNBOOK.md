# BKL-07 — مسار تجديد الإقامة E2E

**البند الأخير المانع للتسليم.** ولا يُغلق بقراءة الشيفرة: مسار يمرّ بأربعة
أشخاص وثلاث نسخ من العقد ومستندين حكوميين لا يُثبِته إلا تشغيله.

الحالات الاثنتا عشرة معرَّفة في `backend/app/renewal.py`. وكل خطوة أدناه
تذكر **الحالة المتوقّعة بعدها** — فإن ظهرت حالة أخرى فالعطل هنا لا فيما
بعدها، ويُسجَّل ويُوقَف الشوط.

---

## قبل البدء

### 1) الحسابات — أربعة أشخاص لا حساب واحد

```bash
cd /app/backend && python -m app.provision_accounts --company 1
```

فحص لا يكتب. راجع الأسماء المقترحة، ثم:

```bash
cd /app/backend && python -m app.provision_accounts --company 1 --apply
```

كلمات المرور تُطبع **مرة واحدة**، مختلفة لكل شخص، ويُطلب تغييرها عند أول
دخول. سلّم كلًّ كلمته مباشرة — لا في ملف ولا جروب ولا تقرير.

### 2) نظافة البيئة

```bash
cd /app/backend && python -m app.remediate_seed_accounts --apply --deactivate-qa
```

### 3) جاهزية إخراج العقد

```bash
curl -s https://hrms-kuwait-production.up.railway.app/api/health/deep
```

في `gov_contract` يجب أن ترى `"status":"ok"` و`can_render_pdf: true`
وأسماء خطوط **عربية صريحة** في `arabic_fonts_found`. غير ذلك يُوقف
الشوط: العقد سيخرج بمربّعات فارغة والتوليد سيبدو ناجًحا.

### 4) موظف صالح للاختبار

إقامته تنتهي خلال **31–90 يوًما** (يفتح المسار المبكر بكل بوّاباته).
وأكثر من 90 يوًما لا يُسمح بالطلب أصًلا — وهذا سلوك صحيح لا عطل.

## فحص العقد (الخطوة 8) — الأهمّ

ملف الهيئة يطلب `SimplifiedArabic` و`Times New Roman`، وهما خطّان
مرخَّصان لا يُثبَّتان على الخادم، فيستبدلهما LibreOffice. والاستبدال قد
يزيح التخطيط. قارن بالأصل:

- [ ] الشعار والترويسة في أعلى الصفحة الأولى
- [ ] العمودان (عربي/إنجليزي) متحاذيان
- [ ] عدد الصفحات كعدد صفحات الأصل
- [ ] البنود المشطوبة تطابق نوع العقد المسجَّل (محدّد/غير محدّد)
- [ ] الاسم والرقم المدني ورقم الجواز والمسمّى والراتب — كلها معبّأة
- [ ] لا يظهر أي حقل بعلامة عدم التعبئة
- [ ] لا مربّعات فارغة مكان الحروف

انزياح التخطيط يُعالَج بقاعدة استبدال صريحة في fontconfig، لا بخطّ
مرخَّص. أرسل صورة الصفحة عند الانزياح.

## ما يُسجَّل عند التعثّر

رقم الخطوة، والحالة التي ظهرت مقابل المتوقّعة، والحساب المستعمَل، ونصّ
رسالة الخطأ كما ظهرت. الحالة الخاطئة أهمّ من الرسالة: هي التي تحدّد
موضع العطل في المحرّك.

**ولا يُقال إن النظام سُلّم قبل مرور العشرين خطوة كاملة.**
