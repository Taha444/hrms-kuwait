# Kuwait HRMS — Business Workflow & Document Outputs V2.2

## المرجع الحاكم
المواصفة التنفيذية V2.2 (13 يوليو 2026). عند أي تعارض بين هذا الملف والمواصفة، **المواصفة هي المرجع**.
V1.4 تُعتبر **مستبدَلة** في أقسام الكتالوج والمسارات — لا تُرقَّع تقنيا.

## المبدأ الذي يحكم كل قرار هندسي
النظام ليس «طلبا يمر على أشخاص ثم يُطبع مساره». هو **Case Management داخلي ينتهي إلى أثر عمل + وثيقة مستقلة عند الحاجة**.

> الموافقة تمنح السلطة لإتمام الأثر · المستند يثبت النتيجة · سجل التدقيق يثبت كيف وصل النظام إليها.
> **ثلاثة كائنات مرتبطة — وليست ملفا واحدا.**

## ترتيب البناء الإلزامي
**لا تُصلح المسارات الحالية واحدا واحدا مع الإبقاء على نموذج الصلاحيات نفسه** — سيعيد ذلك إنتاج المشكلة في صور مختلفة.

```
0. اعتماد الأعمال والقانوني  →  1. تنظيف الكتالوج (53→29)
→  2. المحرك والصلاحيات      →  3. Pilot منخفض المخاطر
→  4. العمليات المتخصصة      →  5. الخروج والمستندات
→  6. الترحيل والإطلاق
```

## السكيلز — اقرأ المناسب قبل أي كود
| السكيل | متى |
|---|---|
| `hrms-workflow-engine` | أي عمل على المحرك، الخطوات، الحالات، المهام، policy rules |
| `hrms-request-catalog` | أنواع الطلبات، كتالوج الأدوار، تعريف مسار WF محدد |
| `hrms-permissions-sod` | الصلاحيات، RBAC، الفصل بين الواجبات، الخصوصية |
| `hrms-document-output` | طبقة المخرجات، دورة حياة المستند، كتالوج Layouts والمستندات |
| `hrms-document-templates` | صياغة القوالب، الحقول، التوقيع، QR |
| `hrms-ui-actions` | الشاشات، شريط الإجراءات، الأزرار |
| `hrms-acceptance-verification` | التحقق، الاختبارات، بوابات المراحل |
| `hrms-legacy-migration` | حذف/دمج/ترحيل أي كود قديم |

## الممنوعات المطلقة
- زر Approve/Reject عام في تفاصيل الطلب
- صلاحية واحدة `approve_request` لكل الأنواع
- حدود سياسة مكتوبة داخل الكود بدل `policy_rule`
- حالات الطباعة داخل حالة الطلب
- Super Admin كموافق افتراضي
- إنشاء طلب جديد عند كل إعادة معلومات
- HTML/JS حر في مسار توليد المستند
- توليد مستند حكومي بشعار حكومي
- إعادة توليد مستند بعد التوقيع
- طباعة سجل الطلب كأنه مستند رسمي

## قاعدة الإثبات
**لا يُقفَل بند بادعاء.** كل بند في `.claude/hrms/status.json` يُقفَل بـ `pass` يحتاج دليلا: مسار ملف اختبار، أو استعلام يثبت القيد، أو مخرَج فعلي.

```bash
python3 .claude/hrms/scripts/check.py --init      # أول مرة
python3 .claude/hrms/scripts/check.py --pending   # الناقص
bash .claude/hrms/scripts/antipattern-scan.sh .   # الأنماط الممنوعة
```

## بوابات خارج نطاق المهندس
