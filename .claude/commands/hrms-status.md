---
description: تقرير حالة المعالجة الحالية
---

```bash
python3 .claude/hrms/scripts/defects.py
python3 .claude/hrms/scripts/defects.py --sev blocker
```

اعرض:
1. **الحكم الحالي**: هل بقي أي blocker مفتوح؟ لو نعم → NO-GO
2. نسبة الإغلاق لكل عنقود
3. البنود المغلقة حديثا مع أدلتها
4. البنود العالقة في `blocked` وما تحتاجه من قرار خارجي
5. **أعلى 3 بنود للعمل التالي** مع سبب الترتيب

اذكر أيضا أي بند أُغلق بـ `fixed` ودليله ضعيف (بلا commit ولا ملف اختبار ولا مخرَج) — هذه تحتاج إعادة تحقق قبل الـ Retest.
