---
description: ولّد تقرير المراجعة النهائي
---

اقرأ سكيل `hrms-audit-reporting`.

```bash
python3 .claude/hrms/scripts/findings.py --roots
python3 .claude/hrms/scripts/findings.py --report > audit-report.md
```

ثم **أكمل التقرير يدويا**:
1. **الرأس**: الرابط · البيئة · Build · Commit · Migration Version · الأدوار المستخدمة
2. **الملخص التنفيذي** بلغة يفهمها غير التقني
3. **الجذور المشتركة** — أهم قسم. عشرون نتيجة قد تكون خمسة جذور
4. **ترتيب الإصلاح** بالاعتماد التقني لا بالخطورة وحدها:
   ما يمنع الاختبار → critical أمني → فساد بيانات → جذور تغلق عدة بنود → الباقي
5. **ما لم يُفحص** — لا تحذفه
6. **حدود المراجعة** — اكتبها بصراحة

## قبل التسليم
- [ ] كل نتيجة `critical` أو `high` لها خطوات تكرار
- [ ] الأدلة منقّاة من البيانات الشخصية
- [ ] لا كلمات سر ولا توكنات في التقرير
- [ ] النتائج التلقائية من probe **مؤكَّدة يدويا** لا منسوخة كما هي
- [ ] ملفات `AUDIT_` نُظّفت أو أُدرجت للتنظيف
