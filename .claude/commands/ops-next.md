```bash
python3 .claude/hrms/scripts/ops.py --next
```

## قبل أي كود — الأسئلة الأربعة من سكيل `hrms-guardrails`
```
1. هل يمس واحدة من القواعد العشرين؟   → توقّف واطلب موافقة
2. هل هو من السبعة تحقيقات؟           → احسمه أولا
3. بيانات اختبار أم منتج؟             → صنّف قبل التعديل
4. كيف سأثبت الإنجاز E2E؟             → حدّد قبل الكتابة
```

لو السكريبت نبّه بتحقيق غير محسوم في نفس المنطقة — **احسمه أولا**.

## التنفيذ
1. اقرأ السكيل المرتبط بالبند
2. افحص الكود الفعلي — لا تفترض
3. نفّذ في الجذر لا في العرَض، وعلى الخادم لا في الواجهة فقط
4. **اذكر أي بنود أخرى يغلقها نفس الإصلاح** — كثير منها يتشارك جذرا

## الإثبات
حدد أي سيناريو DOD يثبت البند، ونفّذه فعليا:
```bash
python3 .claude/hrms/scripts/ops.py --dod-show DOD-XX
```

`endpoint = 200` أو `button works` أو `record saved` **ليست إثباتا**.

## الإغلاق
```bash
python3 .claude/hrms/scripts/ops.py --set <ID> done --note "<commit / DOD-XX / مخرَج>"
```

## بعد الإصلاح
أعد اختبار القواعد التي مسست منطقتها — بالذات `P1-04` الإصدارات و `closure-check` لو لمست التجديد.
