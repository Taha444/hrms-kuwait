description: جهّز مراجعة الباكند وافحص الجاهزية
---

اقرأ سكيل `hrms-backend-audit-method` ثم:

1. **اسأل الأسئلة الأربعة**: الرابط والبيئة · حسابات الأدوار الثمانية · الوصول للكود · الوصول لقاعدة البيانات (قراءة).
2. **حذّر إن كانت البيئة نسخة عميل**: قراءة وفحص ساكن فقط، ولا اختبار كتابة.
3. **جهّز البيئة**:
```bash
cp .claude/hrms/scripts/env.example.sh .claude/hrms/scripts/env.sh
```
اطلب من المستخدم ملأه بنفسه. **لا تكتب أي كلمة سر في أي ملف أو رسالة.**
تأكد أن `env.sh` و `audit/evidence/` في `.gitignore`.

4. **ابدأ السجل**:
```bash
python3 .claude/hrms/scripts/findings.py --init
```

5. **اختبار اتصال سريع**: هل كل دور يسجّل دخولا؟ أي دور يفشل يوقف فحص مساراته — أبلغ.

اعرض: ما يمكن فحصه وما لا يمكن ولماذا. **لا تدّعِ الشمول قبل معرفة المتاح.**
