---
description: ولّد تقرير التسليم Fixed / Not Completed للمراجع
---

```bash
python3 .claude/hrms/scripts/defects.py --report
```

اقرأ سكيل `hrms-release-readiness`، ثم اكتب تقرير التسليم بالشكل المطلوب في طلب المراجعة:

## رأس التقرير
```
Build Version:      
Full Commit SHA:    
Deployment Time:    
Migration Version:  
Environment:        
```

## الجسم
جدول بكل بند: المعرّف | الخطورة | **Fixed / Not Completed** | الوصف المختصر | الدليل

رتّبه بالخطورة ثم بالعنقود.

## الخاتمة
- عدد الـ blockers المغلقة من الإجمالي
- **البنود Not Completed مع السبب** — لا تخفِ شيئا، المراجع سيكتشفه
- البنود `blocked` وما تحتاجه من قرار خارجي (اعتماد نص قانوني، حدود سياسة، توقيع مالك)
- قائمة تنظيف بيئة العميل من سكيل الجاهزية، مع علامة لكل بند

## قبل الإرسال — تحقق من
- [ ] لا يوجد blocker مفتوح
- [ ] كل بند `fixed` له دليل حقيقي
- [ ] بيانات الدخول التجريبية معطلة
- [ ] بيانات QA منظفة (شهادة أحمد محمود علي، الشركة المكررة، 2FA على QA Employee Test)
- [ ] لم تُرفع Build جديدة بعد آخر اختبار

**لا تكتب Fixed لبند لم تختبره.** الـ Retest سيكشفه وسيكلف دورة كاملة.
