اقرأ سكيل `hrms-delivery-package`، ثم:

```bash
python3 .claude/hrms/scripts/delivery.py --init    # أول مرة
python3 .claude/hrms/scripts/delivery.py --critical
python3 .claude/hrms/scripts/delivery.py --pending
```

لكل بند غير مكتمل، **افحص فعليا** لا تسأل فقط:
- النسخ الاحتياطي: هل مجدول؟ متى آخر نسخة؟ **هل جُرِّب الاسترجاع؟**
- المراقبة: هل تصل تنبيهات فعلا؟ إلى من بالاسم؟
- الحسابات: جرّب بيانات الدخول التجريبية — هل تعمل؟
- البيانات: هل بيانات QA موجودة في بيئة العميل؟
- الوثائق: هل موجودة فعلا؟ افتحها واقرأها

حدّث الحالات:
```bash
python3 .claude/hrms/scripts/delivery.py --set DLV-17 done --note "<الدليل>"
python3 .claude/hrms/scripts/delivery.py --set DLV-61 client --note "بانتظار مراجعة محامي العميل"
```

اختم بـ:
- **الحكم**: جاهز / غير جاهز — مع البنود الحرجة الناقصة بالاسم
- ما هو **مسؤولية العميل** لا مسؤوليتك (اعتماد قانوني، قرارات سياسة، استضافة)
- تقدير زمني واقعي لإغلاق الناقص
- **لا تحدد موعد تسليم قبل معرفة حجم الناقص**
