# تنظيف أداة الصيغ والنماذج

## نطاق العطل — محدد بدقة
> مسار المستند الناتج من **Request Workflow سليم فعلا**.
> العطل **محصور في أداة الصيغ والنماذج**.

هذا التحديد مهم: **لا تعدّل مسار المستندات في الطلبات**. المشكلة في الأداة المنفصلة فقط.

## 1. حذف العناصر النائبة الظاهرة
يُشال نهائيا من المخرَج:
```
[____]
[Bank/Embassy/Other]
```

القاعدة: **حقل لم يُملأ لا يُطبع نائبه.** إما:
- يُملأ من مصدره
- أو يُحذف السطر كاملا
- أو يُطلب من المستخدم قبل التوليد

`[Bank/Embassy/Other]` تحديدا يبدو خيار Profile لم يُحسم — فاجعله **Profile يُختار قبل التوليد** لا نصا مطبوعا.

## 2. الرقم الوظيفي بدل معرّف قاعدة البيانات
```
employee_no  ✓     DB id  ✗
```
معرّف قاعدة البيانات **تفصيلة داخلية** لا تظهر في مستند يخرج للموظف أو لجهة خارجية.

ابحث عن كل موضع يطبع `id` وبدّله بـ `employee_no`. لو الموظف بلا رقم وظيفي، ولّده أو أوقف التوليد — لا تطبع رقم الصف.

## 3. القوالب الخمسة للمراجعة
```
PR-001 · PR-006 · PR-008 · PR-009 · PR-032
```
لكل قالب افحص:
- [ ] لا `[____]` ولا `[Bank/Embassy/Other]` ولا أي نائب ظاهر
- [ ] `employee_no` لا `id`
- [ ] لا أسماء حقول تقنية (`allowances_total` · `gross_salary` · `target_entity`)
- [ ] لا تكرار في النص («شركة شركة» · «د.ك د.ك») — سببه غالبا أن القالب يضيف البادئة والقيمة تحملها أصلا
- [ ] النسخة الإنجليزية تستخدم الاسم الإنجليزي للشركة
- [ ] لا Timeline ولا أسماء موافقين ولا role codes
- [ ] العربية RTL سليمة والأرقام غير معكوسة
- [ ] عنوان المستند نتيجة لا طلب: «شهادة راتب» لا «طلب شهادة راتب»

اذكر لكل قالب: ماذا وجدت وماذا صححت.

## 4. قاعدة عامة
مصادر البيانات إلزامية:
```
الراتب      → Payroll المعتمد، لا payload الطلب
اسم الشركة  → Company master، لا نص حر
رقم المستند → مستقل عن رقم الطلب
```

## التحقق
ولّد كل قالب من الخمسة فعليا، استخرج نصه، وافحص قائمة الثمانية. **لا تحكم من قراءة الكود** — القالب قد يبدو سليما ويخرج معطوبا.

## البند
`FRM-01` — القوالب الخمسة نظيفة من النوائب والمعرّفات الداخلية والأسماء التقنية.
