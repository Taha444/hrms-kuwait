## قواعد Legacy Aliases والترحيل (§24.5)
- كل تعريف يخزّن: `canonical_code`, `profile_code`, `layout_code`, `legacy_aliases[]`.
  مثال: `PRN-004 → OD-002 / BANK / LAY-01`.
- أي استدعاء قديم لكود PRN يحله **Alias Resolver** إلى نفس التعريف Canonical — **ولا ينسخ قالبا جديدا**.
- المستندات القديمة تُحفظ كأرشيف غير قابل للتعديل مع `legacy_template_code`؛ الجديدة تحمل `document_definition_version` و `layout_version`.
- **يُمنع حذف Alias** قبل: نجاح ترحيل البيانات + تحديث كل API/Job/Permission + مرور اختبارات Regression + انتهاء مدة توافق معلنة.
- إدارة المحتوى تعدّل النصوص والحقول داخل تعريف المستند أو Profile؛ إدارة الهوية تعدّل Layout واحدا فتنعكس على المستندات التابعة عند نشر نسخة جديدة.
