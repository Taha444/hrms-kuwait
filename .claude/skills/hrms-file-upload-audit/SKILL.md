# مراجعة الملفات والتخزين

## قاعدة السلامة
**الرفع كتابة.** Staging أو Demo فقط. لا ترفع ملفات اختبار على ملف موظف حقيقي.
كل ملف اختباري يحمل بادئة `AUDIT_` ليسهل تنظيفه، **ونظّفه بعد الانتهاء**.

## 1. التحقق على الخادم لا في الواجهة
```bash
# امتداد خطر
curl -F "file=@shell.php" "$B/api/documents/upload" -H "Authorization: Bearer $T"
# امتداد مزدوج
curl -F "file=@evil.pdf.php" ...
# نوع معلن مخالف للمحتوى
curl -F "file=@script.js;type=image/png" ...
# SVG بمحتوى نشط
curl -F "file=@active.svg" ...
# ملف ضخم
curl -F "file=@huge.bin" ...   # 100MB
# ملف فارغ · اسم فيه ../ · اسم طويل جدا · اسم بمحارف يونيكود
```
المتوقع: رفض بكل الحالات **من الخادم**.

**التحقق بالمحتوى (magic bytes) لا بالامتداد ولا بالـ MIME المعلن.**

**تعارض موثق:** الشاشة تقول 500KB ورسالة الخطأ تقول 15MB. وحّد الحد بين الواجهة والخادم واعرضه بدقة.

## 2. حماية التخزين
```bash
# رابط مباشر بلا توكن
curl -I "$STORAGE_URL/documents/passport_12.pdf"        # المتوقع 403
# بحساب ممنوع
curl -H "Authorization: Bearer $ACCOUNTANT_T" "$B/api/documents/5/download"   # 403
# تخمين مسار
curl "$B/storage/employees/1/passport.pdf"
```

```
[ ] لا Storage URL ولا مسار ملف في أي استجابة API
[ ] روابط التنزيل موقّعة ومحدودة المدة
[ ] الـ bucket غير عام
[ ] صلاحية تنزيل المستند مستقلة عن صلاحية عرض الطلب
[ ] تنزيل كل ملف مسجّل في Audit
```

## 3. مسار التوقيع — اختبار كامل
هذا المسار يحتاج **توليد صورة توقيع اصطناعية** واستخدامها.

```bash
python3 .claude/hrms/scripts/make_signature.py -o /tmp/AUDIT_sig_v1.png
python3 .claude/hrms/scripts/make_signature.py -o /tmp/AUDIT_sig_v2.png --seed 7
```

### السيناريو
```
1. [موظف بلا توقيع] ارفع v1        → يُقبل مباشرة (أول رفع)
2. [نفس الموظف] حاول استبدال v1 مباشرة  → مرفوض، يجب أن ينشئ طلبا
3. أنشئ طلب استبدال بسبب + ارفع v2  → v2 تصبح Pending و v1 تبقى Active
4. [HR] ارفض                        → v1 ما زالت Active
5. أنشئ طلبا جديدا وارفع v2 مجددا
6. [HR] وافق                        → v2 Active و v1 في History
7. اطلب /api/me/signature/history   → هل يعرض v1 و v2 والمحاولة المرفوضة؟
8. [PRO] اطلب سجل توقيع موظف        → 403
9. حاول تنزيل صورة التوقيع برابط مباشر → 403
```

**بلاغ موثق:** الاستبدال شغّال بالكامل لكن `/api/me/signature/history` يرجع فارغا. تحقق من هذا في الخطوة 7.

### قواعد التوقيع
```
[ ] أول رفع مباشر · أي استبدال بعده بطلب وسبب
[ ] القديم Active حتى الموافقة
[ ] الرفض يبقي القديم
[ ] كل النسخ محفوظة بتاريخها وسببها ومن وافق
[ ] لا endpoint قديم يسمح بالاستبدال المباشر
[ ] المستند المُصدَر يحتفظ بنسخة التوقيع وقت إصداره
[ ] التوقيع يُضاف عند Approval فقط — لا عند Reject أو Needs Info أو Return أو المشاهدة
```

## 4. مستندات التجديد
```
1. [PRO] ابدأ معاملة تجديد
2. ولّد العقد الحكومي → افحص الملف: يبدأ بـ %PDF · Content-Type صحيح · عربية سليمة
3. أرسله للموظف → هل وصلت Task حقيقية؟
4. [الموظف] افتح · نزّل → مسجّل في Timeline؟
5. [الموظف] ارفع نسخة موقّعة (استخدم PDF اصطناعي)
6. تحقق في القاعدة: مرتبطة بـ renewal_case و employee و source_contract؟
7. تحقق: النسخة المولّدة الأصلية ما زالت موجودة ولم تُستبدل
8. [PRO] ارفع الحزمة النهائية
9. تحقق: النسخ الثلاث للعقد متمايزة ومحفوظة
```

## 5. المستندات المولّدة
```bash
curl -o /tmp/doc.pdf -D /tmp/h.txt "$B/api/documents/5/download" -H "..."
head -c 5 /tmp/doc.pdf          # يجب %PDF-
grep -i content-type /tmp/h.txt # application/pdf
pdffonts /tmp/doc.pdf           # الخطوط العربية مضمّنة؟
pdftotext /tmp/doc.pdf -        # افحص النص
```
```
[ ] لا Raw JSON ولا role codes ولا Timeline ولا أسماء موافقين
[ ] لا Session token في الرابط
[ ] لا JavaScript داخل الـ PDF
[ ] Idempotency: توليد مرتين بنفس المفتاح = artifact واحد
[ ] Preview لا ينشئ artifact ولا يؤرشف
[ ] Snapshot ثابت — تغيّر بيانات الموظف لا يغيّر المُصدَر
```
**بلاغ موثق:** زر Preview & Print أنشأ وأرشف شهادة راتب فعلية. اختبر هذا.

## 6. النسخ والإصدارات
```
[ ] رفع نسخة جديدة لا يمسح القديمة
[ ] القديمة قابلة للعرض والتنزيل
[ ] الأحدث هي Current
[ ] endpoint قائمة الإصدارات موجود ويعمل
```

## 7. التنظيف بعد المراجعة
```sql
SELECT id, storage_key FROM document_artifacts WHERE storage_key LIKE '%AUDIT_%';
```
اعرض القائمة واطلب الإذن بالحذف — **لا تحذف تلقائيا**.

## التسجيل
- ملف خطر يُقبل → `critical`
- تخزين مكشوف أو تنزيل بلا صلاحية → `critical`
- استبدال توقيع مباشر بلا موافقة → `critical`
- Preview ينشئ artifact → `high`
- حد حجم متعارض → `low`
