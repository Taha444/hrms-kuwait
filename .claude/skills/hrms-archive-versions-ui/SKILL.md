# النسخ السابقة — واجهة فقط

## التشخيص المؤكَّد
> الـ Backend محتفظ بـ v1 و v2 · التنزيل شغّال · الـ Audit شغّال.
> **الواجهة لسه مفيهاش زر أو مكان للنسخ السابقة.**

هذا يبسّط العمل كثيرا: **لا تلمس الخادم ولا نموذج البيانات.** المطلوب واجهة تعرض ما هو موجود بالفعل.

**تحقق أولا** أن الـ endpoints موجودة فعلا (قائمة الإصدارات · تنزيل إصدار محدد). لو ناقصة، أضفها — لكن لا تعيد بناء نموذج الإصدارات.

## المطلوب
```
آخر نسخة على وش الصفحة كـ Current
زر «النسخ السابقة» يفتح قائمة كل الإصدارات
كل إصدار: رقمه · تاريخه · من رفعه · حجمه
عرض وتنزيل أي إصدار قديم
```

## أين تنطبق
| المكان | ملاحظة |
|---|---|
| Company Archive | مطلوب |
| Branch Archive | مطلوب |
| Employee Documents | نفس السلوك |
| مخرجات معاملة التجديد | الإقامة وإذن العمل والعقد الجديدة Current والقديمة History |

## قواعد
- **النسخة الحالية وحدها في الواجهة الرئيسية** — لا تعرض كل الإصدارات في القائمة الأساسية.
- **القديمة لا تُحذف ولا تُستبدل** — رفع نسخة جديدة يضيف ولا يمسح.
- صلاحية عرض النسخ السابقة **نفس صلاحية عرض المستند** — لا تفتحها لمن لا يملك الأصل.
- تنزيل نسخة قديمة **يُسجَّل في Audit** مثل الحالية.
- لو الإصدارات إصدار واحد فقط، **أخفِ الزر** بدل فتح قائمة فارغة.

## عند All Companies
بلاغ منفصل مرتبط: أرشيف الشركة يظهر **صفحة بيضاء** عند اختيار «كل الشركات»، رغم أن الخادم يرجع الرسالة الصحيحة «اختر شركة لعرض أرشيفها».
**اعرض الرسالة** بدل الفراغ. حالة Empty ≠ حالة Loading ≠ حالة Unauthorized.

## التحقق
1. ارفع v2 لمستند له v1
2. الصفحة تعرض v2 كـ Current
3. زر النسخ السابقة ظاهر ويفتح قائمة فيها v1
4. افتح v1 ونزّله — يعمل
5. v1 لم تُحذف من التخزين
6. التنزيل مسجّل في Audit
7. مستخدم بلا صلاحية لا يصل للقائمة ولا للتنزيل المباشر
8. مستند بإصدار واحد لا يعرض الزر
9. جرّب على Company Archive و Branch Archive و Employee Documents
10. اختر All Companies → الرسالة تظهر

## البند
`ARC-01` — النسخ السابقة قابلة للعرض والتنزيل من الواجهة في الأرشيف والمستندات.
