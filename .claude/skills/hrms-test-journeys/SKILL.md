# HRMS Test Journeys — 48 رحلة

## الأداة
```bash
python3 .claude/hrms/scripts/testrun.py --new "جولة قبل التسليم" --build v1.0.1 --commit abc123 --env staging
python3 .claude/hrms/scripts/testrun.py --list --role HR
python3 .claude/hrms/scripts/testrun.py --show EMP-03
python3 .claude/hrms/scripts/testrun.py --next
python3 .claude/hrms/scripts/testrun.py --result EMP-03 fail --note "الإرسال يرفض التواريخ" --evidence run-x/emp03.png
python3 .claude/hrms/scripts/testrun.py --summary
```

```
1. SMK-01,02,03           هل النظام حي؟ هل كل دور يدخل؟ هل الـ endpoints ترد؟
```

**السبب في وضع الأمان مبكرا:** لو الصلاحيات مكسورة، نتائج رحلات الأدوار كلها غير موثوقة — لأنك لن تعرف هل الشاشة ظهرت لأنها مسموحة أم لأن الحارس معطّل.

## قواعد التنفيذ

### كل رحلة تُنفَّذ على الشركتين
`GUF` و `MUF`. البلاغات تثبت أن نفس الـ endpoint يعمل على واحدة ويفشل على الأخرى.
نتيجة `pass` على شركة واحدة = سجّلها `partial` لا `pass`.

### الاختبار بالطبقات الثلاث
لكل رحلة فيها صلاحية أو منع:
```
الواجهة (هل الزر ظاهر؟) → الـ API (اضربه مباشرة) → الأثر (هل تغيّر السجل؟)
```
رحلات `ACC-01` و `PRO-01` و `MGR-01` تنص صراحة على الطبقات الأربع بما فيها Storage endpoint.

### الأثر لا الحالة
الرحلات `EMP-03` و `EMP-05` و `ACC-02` كلها تنتهي بفحص **السجل الفعلي** لا حالة الطلب:
- الرصيد خُصم؟
- سجل الحضور تغيّر؟
- قيد الراتب أُنشئ؟

**طلب يصل Completed ليس دليلا على شيء** — هذا بالضبط عطل `WF-04` الموثق.

### الدليل مع النتيجة
السكريبت **يرفض** تسجيل `fail` بلا `--note`. لكل فشل:
- ماذا فعلت بالضبط (الحساب، الشركة، الصفحة، الخطوة)
- ماذا توقعت
- ماذا حدث (كود الحالة، نص الخطأ، لقطة الشاشة)
- المسار: `.claude/hrms/evidence/<run-id>/`

## بعد الجولة
```bash
python3 .claude/hrms/scripts/testrun.py --report
```
يعرض كل ما فشل مع الدليل والبنود المتأثرة. الكود 1 يعني بقاء blocker.

ثم انتقل إلى سكيل `hrms-bug-workflow` لمعالجة ما فشل — **ولا تصلح أثناء الجولة**، لأن ذلك يفسد خط الأساس ويخلط النتائج.

## توسيع الكتالوج
عند اكتشاف عطل غير مغطى برحلة، **أضف رحلة جديدة** في `.claude/hrms/journeys/catalog.json` بمعرّف جديد، حتى يدخل الـ Retest القادم. الكتالوج وثيقة حية وجزء من التسليم.
