# البنود المؤجلة — مطلوبة قبل التسليم لا قبل AWS

هذه بنود **لا توقف بدء العمل على AWS**، لكنها **تمنع القول إن HRMS سُلّم نهائيا**.

## القائمة

### `BKL-01` — Impersonation fix
تأكيد بعد الـ Push.
عند الانتحال يُسجَّل حقلان منفصلان في التدقيق: `actor` و `original_actor`. والانتحال **لا يمنح اعتمادا ذاتيا** — منتحِل شخصية معتمد لا يعتمد طلبا هو مقدّمه.

### `BKL-02` — Central Audit لقرارات المسار
تدقيق مركزي موحّد لـ `approve` · `reject` · `return` · `resubmit`.
كل حدث يحمل: `actor · original_actor · role · company · branch · entity · action · result · before · after · reason · IP · user agent · correlation id · timestamp`.
**ولا يُسجَّل Success عند فشل العملية.**
مرتبط ببلاغ سابق: حدث `request_completed` ظهر بلا Actor وبلا IP.

### `BKL-03` — المهام القديمة و SLA/digest duplicates
مهام مفتوحة لطلبات منتهية · مهام مكررة · إشعارات SLA و Digest مزدوجة.
```
مهمة واحدة لكل إجراء · إغلاق تلقائي عند الاكتمال أو الرفض أو الإلغاء
منع Orphan و Duplicate · العداد يتغير فورا
```
**مرتبط مباشرة بـ `AWS-02`** — التشغيل المزدوج أحد أسباب التكرار. رتّبهما معا.

### `BKL-04` — «طلب طلب»
تكرار الكلمة في عناوين المهام والطلبات. السبب غالبا أن القالب يضيف بادئة «طلب» والقيمة تحملها أصلا. أزل إحداهما.

### `BKL-05` — أنواع (V1.3)
أنواع Legacy ما زالت ظاهرة لإنشاء طلبات جديدة. تبقى للطلبات التاريخية فقط ولا تظهر في «تقديم طلب».
مرتبط ببلاغ: الواجهة تعرض أكوادا قديمة والخادم يرفضها بـ `LEGACY_ALIAS_BLOCKED`.

### `BKL-06` — عداد المهام الحكومية للمندوب
Dashboard تقول 2 أو 3 والفلتر يقول 0. **الاستعلامان مختلفان** — وحّدهما.

### `BKL-07` — مسار تجديد الإقامة E2E
**لم يُقفل** بسبب عدم توفر جلسات Employee و Supervisor.
هذا البند مختلف عن البقية: ليس عطلا صغيرا بل **مسار كامل غير مُختبَر**، بالتفصيل المتفق عليه (المندوب → العقد → الموظف يوقّع ويرفع → المندوب → الحكومة → الحزمة النهائية → OCR → تحديث الملف → الإغلاق).

**لا تعتبر HRMS مُسلّما قبل إغلاقه.**
المطلوب أولا: **تجهيز حسابي Employee و Branch Supervisor** — بدونهما لا يمكن الاختبار أصلا. اجعل هذا أول خطوة لا آخرها.

## الترتيب المقترح
```
أثناء العمل على AWS:
  BKL-07 (تجهيز الحسابات فقط)  ← يفتح الاختبار لاحقا

بعد استقرار AWS:
  BKL-03 + AWS-02   ← نفس الجذر، معا
  BKL-02            ← يفيد كل ما بعده
  BKL-01
  BKL-05
  BKL-06 · BKL-04   ← صغيران

قبل التسليم:
  BKL-07 كاملا      ← المسار E2E
```

## قاعدة
هذه القائمة **ليست مفتوحة للإضافة**. أي بند جديد يُسجَّل في سجل العيوب لا هنا، حتى تبقى قائمة «قبل التسليم» محددة وقابلة للإغلاق.
