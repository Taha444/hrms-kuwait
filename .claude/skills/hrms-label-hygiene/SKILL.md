# تسرب القيم الداخلية للواجهة

## الأعراض
| ما يظهر | ما يجب أن يظهر |
|---|---|
| `طلب شهادة راتب (V1.3)` | `طلب شهادة راتب` |
| `indefinite` | `غير محدد المدة` / `Indefinite Term` |

## الجذر
طبقة العرض **تطبع القيمة الداخلية مباشرة** بدل تمريرها على طبقة الترجمة.

## 1. لواصق الإصدارات
`(V1.3)` لاصقة داخلية للتمييز أثناء الترحيل، تسرّبت لكتالوج الطلبات.

- الاسم المعروض **حقل مستقل** عن الكود الداخلي — لا تشتق أحدهما من الآخر
- التمييز بين إصدارات النوع يكون بـ `is_legacy` و `version`، **لا بالاسم**
- الأنواع القديمة **لا تظهر أصلا** لإنشاء طلبات جديدة (مرتبط ببلاغ `LEGACY_ALIAS_BLOCKED`)

لو ظهرت `(V1.3)` لأن هناك نوعين بنفس الاسم، فالمشكلة أعمق: **نوعان نشطان لنفس الخدمة**. وحّدهما بدل تمييزهما بلاصقة.

## 2. قيم enum
`indefinite` قيمة داخلية لا نص عرض. القاعدة:
```
كل enum يُعرض للمستخدم له خريطة ترجمة بالعربية والإنجليزية
```
ينطبق على: الواجهة · التقارير · **التصدير CSV/XLSX** · PDF · الإشعارات.

**التصدير أكثر ما يُنسى** — يُبنى غالبا بمسار مستقل يتجاوز طبقة الترجمة.

### القيم الخام المرصودة سابقا
```
indefinite · active · delegate · digest · sla_escalation · prepared · residency
qr · gps · both · none      (أُصلحت — تحقق أنها لم تعد)
```
**افحص كل enum في النظام لا هذه فقط.** ابحث عن القيم المعروضة بلا مرور على دالة الترجمة.

## 3. مبدأ عام
```
القيمة الداخلية  →  للتخزين والمنطق والـ API
النص المعروض     →  للمستخدم، من طبقة ترجمة، بلغته
```
لا يُطبع للمستخدم: `enum` خام · `role code` · `field name` · `template code` · `DB id` · لاصقة إصدار.

**المخالفة الأكثر تكلفة**: طباعة قيمة خام في **مستند رسمي** يخرج لجهة خارجية.

## 4. فحص شامل
تصفّح بالعربي وابحث عن أي كلمة إنجليزية بحروف صغيرة و`snake_case`. غالبا قيمة خام.
ثم بدّل للإنجليزي وكرر — الإنجليزي أيضا يحتاج نصا مفهوما، لا `sla_escalation`.

غطّ: القوائم · الفلاتر · التقارير · **التصدير** · PDF · الإشعارات · رسائل الخطأ · حالات الفراغ.

## التحقق
1. الكتالوج بالعربي والإنجليزي — لا `(V1.3)` ولا أي لاصقة
2. التقارير — لا `indefinite` ولا قيم خام
3. **صدّر CSV و XLSX** وافتحهما — نفس الفحص
4. PDF — نفس الفحص
5. الإشعارات ورسائل الخطأ
6. أي enum بلا ترجمة = عطل مسجّل
7. لا نوعان نشطان لنفس الخدمة
