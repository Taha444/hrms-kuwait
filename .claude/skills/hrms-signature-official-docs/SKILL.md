# Package 5 — التوقيع الإلكتروني والمستندات الرسمية

## P5-23 — سياسة توقيع لكل مستند
التوقيع الإلكتروني **شغّال**، لكن بعض المسارات القديمة ما زالت بعقلية:
`Download → Print → Sign → Scan → Upload`

### المطلوب
راجع **كل** OD ورequest ومستند، وحدد سياسته من خمسة خيارات:
```
[ ] Employee electronic signature
[ ] Employee acknowledgement
[ ] Company authorized signatory
[ ] Physical external / government signature
[ ] No signature
```

بعد التحديد: **أي خطوة يدوية لم يعد لها سبب قانوني أو تشغيلي تُشال.**

### الحكم على كل حالة
السؤال ليس «هل نقدر نستغني عن الورق؟» بل **«هل الجهة المستقبِلة تقبل التوقيع الإلكتروني لهذا المستند تحديدا؟»**

- مستند داخلي (اعتماد إجازة، إقرار استلام) → التوقيع الإلكتروني كافٍ غالبا
- مستند يُقدَّم لجهة حكومية → **يحتاج قرار العميل ومحاميه**، لا قرارا هندسيا

اعرض الجدول على المستخدم واطلب اعتماده قبل إزالة أي خطوة.

## P5-24 — المخوّلون بالتوقيع

### تحقّق أولا — بند `V-D`
`/api/signatories = []` والـ resolver لا يجد مخوّلا لبعض المستندات.

> **قبل اعتباره Bug في الـ generator، تأكد أنه ليس مجرد Missing Company Setup.**

الفرق جوهري:
- **إعداد ناقص** → الشركة لم تُعرّف مخوّليها. الحل: شاشة إعداد + تحذير واضح
- **فجوة تكامل** → البنية غير موجودة أو الـ resolver مكسور. الحل: بناء

افحص: هل الجدول موجود؟ هل فيه صفوف لأي شركة؟ هل الـ resolver يُستدعى أصلا؟

### البنية المطلوبة (لو موجودة)
```
Company → Authorized Signatories:
  person · role/title · signature
  document scope / OD scope
  effective dates · active/inactive
```
وعند توليد مستند يحتاج توقيع شركة، الـ resolver يختار المخوّل الصحيح **حسب نوع المستند وتاريخ الإصدار**.

### عند غياب الإعداد
> **يظهر Setup Warning واضح بدل silent incomplete document.**

مستند يصدر بمنطقة توقيع فارغة بلا تحذير أسوأ من رفض التوليد. اذكر ما الناقص ومن يضبطه.

## P5-25 — لا توقيع حكومي بدل الجهة (قاعدة حماية)

> **DO NOT CHANGE.**

```
النظام لا "يخلق" مستندا حكوميا رسميا
النظام لا يزوّر توقيع جهة حكومية
```

`OD-013` وما يشبهه: النظام يولّد **form / cover / tracking document** فقط، والأصل الحكومي **يُرفع من الجهة أو الـ PRO** حسب العملية.

**قاعدة حماية 12.** أي «تحسين» يجعل النظام يصدر إقامة أو إذن عمل أو بطاقة مدنية بشعار حكومي مرفوض تماما — وهو تزوير لا عطل واجهة.
